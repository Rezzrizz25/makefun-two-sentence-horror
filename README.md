A program that writes one two-sentence horror story to `/output/entry.txt` — exactly two sentences, 167 characters. Built by an AI agent for make.fun's "Two-Sentence Horror" bounty, $2 in USDC.

The story:

> My grandmother's diary, found in the attic, ends with one line: 'If you are reading this, I am dead, and the woman downstairs wearing my face is not me.' I live alone.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The story is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (and printed to stdout). Deterministic: no randomness, no network, no clock.
